# Tito Portfolio

This is a **personal portfolio website** for **Tito Miya**, a Fullstack Web Developer.  
The website is fully responsive, built with **HTML, Tailwind CSS, and JavaScript**. It showcases skills, services, work experience, and a contact form.

---

## 🖥️ Features

- **Responsive Design**: Works perfectly on mobile, tablet, and desktop.
- **Hero Section**: Introduction with a profile image and a call-to-action button.
- **Skills Section**: Shows 8 major skills like HTML, CSS, JavaScript, React, Tailwind, Bootstrap, Git & Figma.
- **Services Section**: Backend development, Frontend development, and Figma-to-HTML conversion.
- **Experience Section**: Personal projects and online course achievements.
- **Contact Section**: Contact form with Name, Email, Phone, and Message.
- **Footer**: Social links and copyright notice.
- **Mobile Navigation**: Hamburger menu with toggle functionality.

---

## 🛠️ Technologies Used

- **HTML5**
- **Tailwind CSS**
- **JavaScript**
- **Responsive Grid and Flexbox Layouts**
